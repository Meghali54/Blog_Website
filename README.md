# 📝 Flask Blog Application

A lightweight, functional blog engine built with **Python**, **Flask**, and **HTML/CSS**. This project supports user authentication, post creation, and a responsive UI.



## 🚀 Features
- **User Authentication:** Secure Sign Up and Login using Flask-Login.
- **CRUD Operations:** Create, Read, Update, and Delete blog posts.
- **Database Integration:** SQLite (via SQLAlchemy) for storing user and post data.
- **Responsive Design:** Styled with CSS/Bootstrap for mobile and desktop views.
- **Flash Messaging:** Real-time feedback for user actions (e.g., "Post Created!").

---

## 🛠️ Tech Stack
- **Backend:** Python 3.x, Flask
- **Frontend:** HTML5, CSS3, Jinja2 (Templating)
- **Database:** SQLite / SQLAlchemy
- **Security:** Werkzeug (Password Hashing)
